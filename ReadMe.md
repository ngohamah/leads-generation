## Summary 

The main goal of this project was to generate accurate LinkedIn leads for Propeterra (a real estate advisory company) so that they could connect with both agents, property owners or consultants for the global effort to build Global Real Estate Advisory Hub with resources and personnels. This project is just one part of a bigger project.

1 - Task 1: Hunter.io for generating initial leads. Here, feed Hunter.io with a list of company URLs (countries/.../team1.json) related to Real Estate firms we generated using a LLMs. Hunter.io will then return a json payload of the names, email addresses, position, and in some cases phone numbers of the employees. 

2 - Task 2: The generate json payload from Hunter.io (countries/.../team2.json) is then structured using a LLM for consistency in json payload formatting. The output is then later used by the `professional_dorking.py` to query LinkedIn to find out if the initially leads generated by Hunter.io were accurate. In cases where the information was accurate, we enrich the json payload with additional information like the agent, contact or lead's LinkedIn address and LinkedIn bio 

3 - Task 3: The enriched data is then saved (countries/.../team5.json) which is an organization of all verified leads and their LinkedIn profiles information ready for display on Propeterra's visualization dashboard.
