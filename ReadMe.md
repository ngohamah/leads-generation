## Summary 

The main goal of this project is to generate accurate LinkedIn leads for Propeterra (a real estate advisory company) so that they can connect with agents, property owners, and consultants for the global effort to build a Global Real Estate Advisory Hub with resources and personnel. This project is one part of a larger initiative.

**Task 1:** Hunter.io for generating initial leads. We feed Hunter.io a list of company URLs (countries/.../team1.json) from real estate firms that we generated using LLMs. Hunter.io returns a JSON payload containing employee names, email addresses, positions, and phone numbers (when available).

**Task 2:** The JSON payload generated by Hunter.io (countries/.../team2.json) is then structured using an LLM for consistency in formatting. The output is used by `professional_dorking.py` to query LinkedIn and verify the accuracy of the initial leads from Hunter.io. When information is verified as accurate, we enrich the JSON payload with additional data such as the LinkedIn profile URL and professional bio.

**Task 3:** The enriched data is saved to (countries/.../team5.json), containing an organized collection of all verified leads with their LinkedIn profile information, ready for display on Propeterra's visualization dashboard for outreach by the marketing and sales teams.

## Conclusion

This project demonstrates how lead generation can combine multiple tools: Hunter.io for initial prospecting, LLMs for data processing and JSON formatting, and the Google Search Engine API for accurate LinkedIn profile verification.
